# Brand - LineScope

Status: active

LineScope uses a flat operator-console visual system for live sports-data intelligence.

## Palette

- Background: `#080A0D`
- Surface: `#0D1117`
- Surface 2: `#111827`
- Border: `#1F2937`
- Text primary: `#F9FAFB`
- Text secondary: `#9CA3AF`
- Text muted: `#6B7280`
- Success: `#22C55E`
- Warning: `#F59E0B`
- Danger: `#EF4444`
- Info: `#38BDF8`

## Rules

- No gradients, glassmorphism, glow, orb graphics, or 3D illustration.
- Use compact spacing, sharp borders, icon-led controls, tables, drawers, tabs, badges, and mono IDs.
- Copy stays in analytics language and never suggests wagering actions.
